# 💳 Predict Credit Card Default Data Using Logistic Regression
⭐ Academic Project | Machine Learning | Credit Risk


## 📌 Overview

This project focuses on predicting whether a customer will default on their credit card using logistic regression. The study aims to understand customer financial behavior and identify key risk factors associated with credit default.

## 🎯 Objectives

* Build a classification model for credit risk
* Identify key factors influencing default behavior
* Evaluate the effectiveness of logistic regression in financial risk prediction

## 📊 Dataset

The dataset consists of 10,000 observations and includes both numerical and categorical variables relevant to customer financial profiles.

**Variables include:**

* Balance
* Income
* Student status
* Default (Yes/No)

## 🛠 Tools & Technologies

* R Programming
* Statistical Modeling

## 📈 Methodology

The analysis followed a structured approach, including data preprocessing, exploratory data analysis, and model development. The dataset was split into training and testing sets using an 80:20 ratio. A binary logistic regression model was then applied to estimate the probability of default.

## 📊 Model

A logistic regression model was used to estimate the likelihood of a customer defaulting based on input variables. The model captures the relationship between predictors and the probability of default.

## 📈 Evaluation Metrics

Model performance was evaluated using:

* Accuracy
* AIC (Akaike Information Criterion)
* ROC Curve

## 💡 Key Insights

* Credit balance is the most significant predictor of default risk
* Income shows a relatively weaker influence
* Logistic regression provides effective results for binary classification problems
